# The application stack: React, Vite and the TanStack libraries, in strict TypeScript

The UI is a static single-page app built with React 19 and Vite 8, in TypeScript 6 with the strictest settings. TanStack Router handles routes, with search params validated by Zod 4. TanStack Query holds server state. TanStack Table and TanStack Virtual render the lists. React Hook Form and Zod handle forms. react-i18next handles messages, with one JSON namespace per feature. `Intl` formats money, numbers and dates. The API client is generated from the backend's OpenAPI contract with openapi-typescript, openapi-fetch and openapi-react-query, and is never written by hand (backend ADR-0008). Sign-in uses oidc-client-ts with react-oidc-context: PKCE, refresh tokens and `sessionStorage`, with no backend-for-frontend. Components come from shadcn/ui on Base UI with Tailwind 4. There is no client state library. Server data lives in Query, view state in the URL, form state in React Hook Form and the session in react-oidc-context.

We chose the most mainstream option at each step. The people maintaining this app are not frontend specialists and lean on documentation and coding agents. React has the largest ecosystem and the most agent familiarity, and plain TypeScript checks all of it. Vue and Svelte templates can't be checked by TypeScript 7 until 7.1. TanStack Router was chosen over React Router because it type-checks routes, links and search params without framework mode, which suits filter-heavy tables. The generated client is types-only, about 2.6 kB, and clean under the strictest settings. Orval is the fallback if openapi-typescript stops being maintained. react-i18next was preferred to Lingui because it needs no build step, at the cost of non-ICU plurals. A backend-for-frontend is what the browser-apps BCP prefers, but it is a runtime server and would break the static build. It remains the upgrade path if Wallet Accountant becomes a hosted service.

We stay on TypeScript 6 because TypeScript 7 breaks typescript-eslint and openapi-typescript until 7.1 restores the compiler API. We move to 7.1 once both support it. We rejected Mantine as the design system: it covers more out of the box, but its large tables rendered about twice as slowly in the prototype and its look risked staying generic. MUI, Ant Design and React Aria Components were ruled out earlier, for paid grid features, weak accessibility and the amount of assembly respectively.
